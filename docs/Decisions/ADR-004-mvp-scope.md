\# ADR-004: MVP Scope



\## Status



Accepted



\---



\## Core MVP Features



\* Authentication

\* User Profiles

\* Workspace Management

\* Document Upload

\* Document Processing Pipeline

\* Semantic Search

\* Chat with Documents

\* Chat History

\* Basic User Preferences



\---



\## MVP+ Features



\* Flashcards

\* Quizzes

\* Learning Analytics



\---



\## Phase 2 Features



\* Audio Understanding

\* Image Understanding

\* Study Plans

\* Weak Topic Detection

\* Multi-Workspace Search

\* Citations



\---



\## Phase 3 Features



\* Personalized Tutor

\* Collaboration

\* Exam Simulations

\* Adaptive Learning



\---



\## Rationale



The MVP should validate whether students gain value from learning through AI-powered interaction with their study materials before building advanced learning features.
